# Security policy

A-IEP holds records about children with disabilities, so we take every report
seriously.

## Reporting a vulnerability

**Please do not open a public issue, pull request or discussion.**

Report it privately through
[GitHub's vulnerability reporting](https://github.com/The-Burnes-Center/a-iep/security/advisories/new).
Only the maintainers can see it.

Please include:

- What the issue is, and what someone could do with it
- The steps to reproduce it, or a proof of concept
- The page, API route or file involved
- Your name or handle, if you would like credit

Do not include anyone's real personal information, and do not access, change
or keep data that is not yours while testing. Test against your own account.

## What happens next

We will acknowledge your report, keep you updated while we work on it, and let
you know when it is fixed. With your permission, we will credit you in the
advisory.

## Scope

In scope: the A-IEP web app at [a-iep.org](https://a-iep.org/), its API, and
the code in this repository.

Out of scope: denial-of-service testing, social engineering, spam, and issues
in third-party services we use (report those to the provider).

## Supported versions

Only the version running at a-iep.org is supported. Fixes ship there.
